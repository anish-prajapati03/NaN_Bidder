# NaN_Bidder - Manual QA Testing Project

## Project Overview

NaN_Bidder is a real-time auction web application that allows users to participate in online auctions and place bids.

This project focuses on manual testing of the application to identify functional issues, verify business requirements, and ensure a reliable user experience.

## Testing Activities

- Requirement Analysis
- Test Scenario Design
- Test Case Design
- Functional Testing
- Smoke Testing
- Regression Testing
- Integration Testing
- Test Execution
- Defect Identification and Reporting
- Bug Tracking
- Test Documentation

## Modules Tested

- User Registration
- Login
- Auctioneer
- Bidder
- Super Admin
- Product/Auction Management
- Bidding
- Auction Management
- Dashboard
- Notifications
- Email Functionality
